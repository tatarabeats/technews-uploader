プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-09-27

対象

tech-news uploader（以下「本ツール」）は、YouTube チャンネル「テックニュース」の運営者本人だけが使う個人用ツールです。

使うデータ

  • YouTube Data API：運営者自身のチャンネルへの動画・字幕・サムネイルのアップロード、公開設定の変更、チャンネル情報の確認
  • YouTube Analytics API：運営者自身のチャンネルの再生数などの集計値の読み取り

保存と共有

  • 認証トークンは運営者のパソコンのローカルにだけ保存し、外部に送信しません。
  • 取得したデータを第三者に販売・共有・広告利用することはありません。
  • 本ツールは Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

Google アカウントの「サードパーティによるアクセス」（https://myaccount.google.com/permissions）から、いつでも本ツールのアクセスを取り消せます。

English summary

This tool is used solely by the channel owner to upload videos to and read analytics for their own YouTube channel. OAuth tokens are stored only on the owner's local computer. No data is sold, shared with third parties, or used for advertising. The tool complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at https://myaccount.google.com/permissions.
